# CodeAlpha_FlashcardQuizApp

📚 Flashcard Quiz App

A simple and interactive Flashcard Quiz App designed to make learning and revision easier. Users can practice questions, reveal answers, and create their own customized flashcards.

✨ Features

- Show and hide answers
- Next and Previous navigation
- Add new flashcards
- Edit existing flashcards
- Delete flashcards
- Automatic saving using Local Storage
- Clean and responsive user interface
- Works directly in a web browser

🛠️ Technologies Used

- HTML5
- Local Storage

🚀 How to Run

1. Download or clone this repository.
2. Open the "flashcard_quiz_app.html" file in a web browser.
3. Start studying using the flashcards.
4. Add your own questions and answers to customize your deck.

🎯 Purpose

The purpose of this project is to create a simple study tool that helps students improve their learning, memory, and revision through interactive flashcards.
